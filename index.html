📱 如何在手机上打开测试
  1. 将本 HTML 文件部署到一个 HTTPS 站点，例如 GitHub Pages / Netlify / Vercel， 或使用本地 HTTPS 服务（见下）。
  2. 确认 ESP32-S3 已上电，固件正在广播，名称前缀为 ESP32S3_CTRL。
  3. 用安卓手机 Chrome 打开页面地址。
  4. 点击「连接设备」，在弹出的设备列表中选择 ESP32S3_CTRL... 并配对。
  5. 连接成功后点击各控制按钮，观察日志区的发送 / 接收记录。
  • 本地调试（PC 同局域网 / 手机需能访问到 PC）： python -m http.server 8000 后用 http://<电脑IP>:8000 访问（localhost 属于安全上下文， 但手机访问电脑需走局域网 IP，此时通常不是安全上下文，需改 HTTPS）。
  • 简单 HTTPS 本地调试（需 Node.js）： npx http-server -S -C cert.pem -K key.pem -p 8443。
